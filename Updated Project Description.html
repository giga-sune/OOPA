Project Idea or Definition:

OOPA is a peer-to-peer rental marketplace that helps people access useful items for a limited time instead of buying them. It connects borrowers with owners who want to earn income from underused belongings such as tools, camping gear, household equipment, electronics, and event supplies.

The app is designed to reduce unnecessary purchases, save money, reduce household clutter, and encourage local resource sharing. Its current core experience supports accounts, item listings, search, saved items, rental requests, owner approval or rejection, Stripe payments, messaging, notifications, ratings, reviews, and paid OOPA Pro subscriptions.

Brief Description of the Project:

OOPA is being developed as one cross-platform mobile application for Android and iOS using Expo, React Native, and TypeScript. A user can act as both a borrower and a lender from the same account. Firebase Authentication provides email-and-password signup and login, while Cloud Firestore stores application data and Firebase Storage stores uploaded listing and profile images.

Borrowers can browse and search listings, apply filters, save items, view item details and meetup locations, choose rental dates, calculate the rental total, submit a request, pay after approval, message the lender, and leave a review. Lenders can create, edit, and delete listings, upload up to eight images, set weekly or monthly pricing, choose a meetup location, use AI assistance to draft a description during development, and manage incoming rental requests.

The backend uses Firebase Cloud Functions to protect listing limits, create Stripe payment intents, manage OOPA Pro subscriptions, synchronize subscription entitlements through webhooks, create rental chats, and generate rental notifications. Free accounts are limited to three active listings, while an active OOPA Pro subscription allows unlimited active listings.

The main target users remain students, urban residents, DIY users, hobbyists, occasional users, and people who want to earn income from items they already own.

Current scope note: Full KYC identity verification, insurance claims, refundable deposits, true escrow, and a complete stored dispute-resolution workflow are not implemented in the current codebase. The app contains a report form, but its submission is currently a user-interface confirmation only. These features are future production work and should not be described as completed.

Tools and Technologies:

  • Mobile Application: Expo SDK 54, React Native 0.81, React 19, and TypeScript
  • Platforms: Android and iOS from one shared React Native codebase; basic Expo web support is also configured
  • Navigation: React Navigation with native-stack and bottom-tab navigation
  • Backend: Firebase Cloud Functions v2 using Node.js and TypeScript
  • Database: Firebase Cloud Firestore with security rules and indexes
  • Authentication: Firebase Authentication using email and password
  • File Storage: Firebase Storage for listing and profile images
  • Payments and Subscriptions: Stripe PaymentSheet, Payment Intents, recurring subscriptions, billing portal, and webhooks; currency is CAD
  • Maps and Location: Expo Location and React Native Maps
  • Notifications: Expo Notifications, Firestore notification records, and Cloud Functions
  • AI Assistance: Gemini API for draft listing descriptions in development mode
  • Testing: Node test runner, Firebase Emulator Suite rule tests, and Cloud Function tests
  • Version Control: Git and GitHub

Database Structures or Database Design:

  • Users: Stores the Firebase user ID, email, username, profile image links, phone number, and timestamps.
  • Properties: Stores owner information, listing images, title, description, brand, condition, fixed or flexible price type, weekly or monthly price, meetup address and coordinates, search keywords, and timestamps.
  • Saved Items: Stored as a subcollection under each user and used to manage favourite listings.
  • Rentals: Stores the property, borrower and owner, rental dates, number of rental units, calculated total, optional message, status, and timestamps. Supported statuses are pending, approved, rejected, completed, and cancelled.
  • Payments: Stores one Stripe payment record per rental, including the amount in cents, CAD currency, Payment Intent ID, attempt number, payment status, and timestamps.
  • Reviews: Stores one borrower review per eligible rental, including the property, reviewer, rating from 1 to 5, review text, and creation time.
  • Chats and Messages: Stores chat metadata for approved rentals and a messages subcollection containing the sender, text, and timestamp.
  • Notifications and Push Tokens: Stores rental request updates and registered Expo push tokens for users.
  • Entitlements and Listing Statistics: Stores OOPA Pro access and each user's active-listing count.
  • Stripe Support Collections: Stores customer mappings and processed webhook event IDs on the trusted backend.

Screens Design:

  • Login and Signup: Creates accounts and signs users in with Firebase Authentication.
  • Home and Search: Displays available listings and supports keyword search, condition, price-range, and price-type filters.
  • Item Details and Map: Shows images, pricing, condition, brand, description, reviews, owner information, and meetup location.
  • Create/Edit Listing: Uploads images, collects listing information and location, provides AI description assistance, and enforces the free listing limit.
  • My Listings and Saved Items: Lets users manage their own listings and revisit favourites.
  • Rental Checkout: Selects dates, adds a message for the lender, calculates the total, and submits a rental request.
  • Orders and Request Details: Separates borrower orders from lender requests and lets a lender accept or reject a pending request.
  • Payment: Lets the borrower securely pay an approved rental using Stripe PaymentSheet and displays payment status.
  • Inbox and Chat: Enables real-time messaging between the borrower and lender after a rental is approved.
  • Reviews: Allows an eligible borrower to submit a rating and written review and displays all reviews for a listing.
  • Notifications: Displays rental request, approval, and rejection updates; final navigation integration still needs completion.
  • Profile and Account Settings: Displays and updates username, email, phone, and profile image, with links to saved items, listings, help, invitations, and subscription management.
  • OOPA Pro Subscription: Displays monthly and yearly Stripe plans, completes subscription payment, shows entitlement status, and opens the Stripe billing portal.
  • Report, Help, and Invite Friends: Provides supporting user-interface flows. Persistent report handling and production referral tracking remain future work.
